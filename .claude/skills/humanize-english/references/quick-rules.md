# Quick rules

Fast mode reads only this file and fixes only what it names.

## Absolute conditions

1. Do not change numbers, dates, units, identifiers, paths, config keys,
   versions, quotations, code or URLs.
2. Do not change the strength of negation, possibility, obligation, condition or
   causation. Stated uncertainty stays uncertain.
3. Do not add an experience, a feeling, a source or an example that is not in
   the draft.
4. Do not normalise the register. Flat declarative prose and first person are
   this blog's voice, not tells.
5. Change-rate warning at 30% and stop at 50%, applied only above 150 words and
   5 sentences. Below that, treat it as advisory and judge by edit count.

## Order of work

1. S1 phrases: preview openings, throat-clearing, inflated diction, "In
   conclusion".
2. Structure: recap closings, lists padded to three, self-answered questions.
3. Connectives: sentence-initial "Additionally / Furthermore / Moreover" chains.
4. Syntax and diction: nominalization chains, empty intensifiers, unquantified
   comparatives.
5. Translationese (section I) — the most likely real problem here, since the
   English is rendered from Korean.
6. Rhythm: only with 5+ sentences, and never on the metric alone.
7. Formatting: whole-sentence bold, em dash density, adjective tables.

## Six-item self check

- [ ] Facts, numbers, identifiers, quotations and code preserved.
- [ ] Modality and causation preserved.
- [ ] Register and person preserved.
- [ ] No "humanity" added that was not in the draft.
- [ ] No S1 left, or a stated reason for each one kept.
- [ ] Change rate inside the safe range.
